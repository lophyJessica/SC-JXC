# 顺诚进销存原型工程

可点击的产品原型，给业务方看。Vue 3 + Element Plus，演示数据存在浏览器本地数据库（IndexedDB），没有后端。

完整约定见 `../../07-UI规范库/前端技术约定.md`。

## 只想看原型

双击 `dist/index.html`（不需要安装任何东西，不需要联网）。

## 要改原型

需要先装 Node.js LTS（20.19 及以上）。在本目录打开终端：

```bash
npm install      # 第一次用时装依赖
npm run dev      # 边改边看，自动打开浏览器
npm run build    # 打包，生成 dist/index.html
```

## 页面右上角

- **演示身份**：切换采购员、采购组长、老板，看不同身份能做什么（只在原型里有）
- **显示角标**：打开后出现 L1、F1、D1 这样的橙色角标，点一下看说明（详见 `../标注/`）
- **重置演示数据**：清掉所有演示操作，恢复初始数据
