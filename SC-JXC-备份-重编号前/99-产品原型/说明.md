# 99-产品原型

放可点击的页面原型和原型标注。

- `前端工程/`：原型工程（Vue 3 + Element Plus），所有单据的原型都做在这里面
  - 只想看：双击 `前端工程/dist/index.html`，不需要安装任何东西
  - 要改：装 Node.js LTS，在 `前端工程/` 下执行 `npm install`、`npm run dev`；改完 `npm run build` 重新生成 dist
  - 顶部"演示身份"可切换采购员、采购组长、老板，看不同身份能做什么
  - 顶部"显示角标"打开后，页面上会出现 L1、F1、D1 这样的橙色角标，点击看说明
  - 顶部"重置演示数据"：演示数据存在浏览器本地，刷新不丢；点它恢复初始数据
  - 代码怎么写、放在哪：见 `07-UI规范库/前端技术约定.md`
- 采购订单原型（08 号提示词产出）：`前端工程/src/views/采购/采购订单/`，打开原型后点左侧"采购管理 / 采购订单"
- `标注/`：每页一个标注文件，解释每个角标（09 号提示词产出）
- 原型不是事实来源。原型上发现的问题，回到字段清单、主PRD 或 Demo PRD 去改，再重新生成原型
- 只保留一套最新原型，持续往前改
