# 【页面名称】原型标注

> 标注是给评审人看的"原型说明书"，用业务语言写，不写技术词。每个角标对应原型上一个带编号的位置。来源不明的写【待确认】。

- 页面：【模块 / 页面名称】
- 原型页面：99-产品原型/前端工程/src/views/【模块】/【单据】/【页面】/（打开原型后的地址：#/【路由】）
- 角标数量：【N】（应与评审PRD 功能清单条数一致）

## 角标 1：【功能点名称】

- 位置：（如"列表页顶部查询区"）
- 说明：（这个位置能做什么，用大白话）
- 规则：（引用主PRD 的规则，原文搬运）
- 来源：主PRD 第五章第 X 条 / Demo PRD 第三章第 X 行 / 字段清单

- 说明：

## 原型上的写法约定

- 每个被标注的元素加属性 `data-anno="角标编号"`，例如 `data-anno="L1"`
- 列表页用 L1、L2…，新增编辑页用 F1、F2…，详情页用 D1、D2…
