# 默认字段校验规范

字段清单里没有特别说明时，按下表执行。字段清单有特别说明的，以字段清单为准。

| 字段类型 | 默认规则 | 示例 |
| --- | --- | --- |
| 单号 | 系统生成，只读，格式见单据目录 | XSDD-20261020-0001 |
| 名称类文本 | 1～50 字，去掉首尾空格 | 客户名称 |
| 备注类文本 | 0～200 字 | 备注 |
| 手机号 | 11 位数字，1 开头 | 13800000000 |
| 数量 | 整数，大于 0，按商品最小单位 | 24 |
| 单价 | 数字，大于等于 0，两位小数 | 3.50 |
| 金额 | 系统计算，两位小数，四舍五入，只读 | 数量 × 单价 |
| 日期 | 年-月-日，默认当天 | 2026-10-20 |
| 下拉选择 | 只能从基础资料中选，不可手输；停用的不出现 | 客户、供应商、商品、仓库 |
| 日期区间 | 结束类日期不能早于开始类日期 | 交货日期不早于下单日期 |
| 创建人、创建时间 | 系统自动记录，只读 | — |

## 校验时机

- 单个字段：离开输入框时校验格式，错误提示显示在字段下方
- 整张单据：点"提交审核"时全量校验，自动滚动到第一个错误位置
- 保存草稿：只校验格式，不校验必填

## 明细行通用规则

- 明细至少要有 1 行才能提交
- 同一张单据里，同一个商品不能重复出现在两行；要加量就改原来那行的数量
- 金额合计 = 各行金额相加，系统计算

## 必填标识

必填字段名称前加红色星号"*"。
